# Design prototypes (not part of the site)

Standalone HTML pages used to choose the new look. They are **not built or deployed**: this folder is outside `src/` and `public/`.
Open `index.html` in a browser (it needs internet for Google Fonts).

| File | What it is |
|---|---|
| `beam.html` | **Chosen direction.** Home page for For Everyone and For Doctors, light and dark, 6 colour palettes, cursor-reactive dust. |
| `calculator.html` | Stand-in for `/tools/bmi-calculator/`, showing how `#height`, `#weight`, `#waist`, `#sex` links open ready to type. |
| `signal.html`, `atlas.html` | The two directions not chosen, kept for reference. |
| `avatar.jpg` | Copy of `src/assets/harsh-maheshwari.jpg` (the round photo stays as it is). |

Decisions and the roll-out plan: `docs/design-direction.md`.
