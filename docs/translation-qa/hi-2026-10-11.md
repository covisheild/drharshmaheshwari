# Hindi QA, 11 Oct 2026 (Phase 1)

Pipeline run on everything translated in Phase 1: the dictionary (`src/i18n/hi.json`, 224 strings, ~2,660 Hindi words) and three
texts (`bmi-cut-offs-for-indians`, `waist-to-height-ratio`, `interpretation-of-the-world`, ~2,100 words with front matter).
Steps as in `docs/translation.md`.

## Open for Harsh (decisions, not errors)

1. **लंबाई for height** in "कमर-लंबाई अनुपात" (waist-to-height ratio). लंबाई is how people ask a person's height in Hindi; the
   reviewer suggested कद or ऊँचाई for the name of the measure. It is a glossary term, so changing it changes every page.
2. **"Reversing obesity"** is now "बढ़ते मोटापे को पलटना" (turning back rising obesity).
3. **Notes added for Hindi readers**, not in the English: "(अंग्रेज़ी में)" after links to English-only pages (For Doctors · Tools,
   the account pages). Keep or drop.

## Not counted as findings (checked)

- `topic` values are translated (`मोटापे की बुनियादी बातें`, `विचार`). This does not change the meaning, but if topics are used as keys (for filters or tag pages) the Hindi pages may not group with the English ones. Check how `topic` is used.
- The BMI description says "than people from Europe" without "at the same BMI". The English description also lacks that hedge, so nothing changed.
- The waist-article note says "heart risk" may scope ambiguously. The English "predicted diabetes, high blood pressure and heart risk" has the same structure, so nothing changed.
- Readability notes from the back-translator (एकतरफ़ा हैश, ऑस्कल्टेशन, रासायनिक रूप से सक्रिय, स्टैटिस्टिक/पैरामीटर) are about clarity, not meaning changes.
