same AI pipeline as every future language (docs/translation.md), so this log measures how good that pipeline is for languages

certainty); **moderate** = changes another claim, or drops/adds a sentence or qualifier; **minor** = wording, tone, unnatural Hindi.
"Caught by pipeline?" = was it already flagged by the automated checks or the back-translation (yes/no).
