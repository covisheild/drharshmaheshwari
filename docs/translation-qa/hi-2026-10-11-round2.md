# Hindi QA, 11 Oct 2026, round 2: calculators and new pages

Scope: the 496 dictionary strings added when every For Everyone page got Hindi (BMI calculator, Activity check, IDRS, STOP-Bang,
unit fields, Learn cards, Privacy; Harsh: "Hindi support is not there in tools / calculators / blogs / guides").
Same pipeline as round 1 (docs/translation.md).

## Results

| Step | Result |
|---|---|
| Automated checks | 0 errors after fixes. New checks this round: library texts must have Hindi (test), every For Everyone page must have a Hindi page (test), Hindi pages must link to Hindi pages (test; it found the guides linking to the English calculator), glossary names (proper names such as "Indian Diabetes Risk Score" are transliterated). |
| Browser | `npm run test:e2e` fills every Hindi calculator (32 cases across all age groups, sexes and score bands) and fails on any English sentence in the results: all pass. It found two lib labels that had no Hindi ("Aerobic activity, upper target", BMI verdict pattern); both fixed. |
| Blind back-translation | 496 strings; notes on unclear Hindi (below). |
| Meaning comparison | **9 critical**, 5 moderate, 18 minor. |
| Fixes | **All 9 critical had one cause**: "energetic" (WHO and ICMR-NIN: moderate-to-vigorous) had been written ज़ोरदार, the word used for "vigorous", so the Hindi asked children for 60 minutes of vigorous activity and the input questions counted vigorous time only. Now "ऊर्जावान (मध्यम से ज़ोरदार)" everywhere, and both words are glossary terms, so the checker enforces the difference. Moderate: IDRS "Vigorous" option तेज़ (also used for brisk walking) → ज़ोरदार; STOP-Bang neck now measured "around the neck at the level of the Adam's apple"; "fatigued" was कमज़ोरी (weakness, a different symptom in a scored question) → सुस्ती; the "(in English)" note after For Doctors links kept on purpose. Minor taken: STOP-Bang "intermediate" no longer the same word as "moderate"; "strapped in" says पट्टे (बेल्ट) में बँधा; IPAQ "20 minutes a day" says "on those days"; adult-equivalent labels. |

**Lesson for the pipeline:** the automated checks cannot catch a wrong-but-plausible clinical term; the back-translation did. For a
new language, write the activity and intensity terms (vigorous, moderate, energetic, light) into the glossary before translating.

## Open for Harsh

- The STOP-Bang, IPAQ and IDRS questions in Hindi are this site's AI translation, not published validated Hindi versions.
- "टमी टाइम" and "सेंसिटिविटी/स्पेसिफ़िसिटी" are kept as loanwords with an explanation beside them.
