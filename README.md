# drharshmaheshwari.com

Source of Dr. Harsh Maheshwari's website. Built with [Astro](https://astro.build), hosted on Cloudflare (Workers).

- `npm install` then `npm run dev` for a local preview.
- `npm run build` produces the static site in `dist/`.
- Content is written in Notion (Website Desk) and published here by a coding agent (Claude Code, or Gemini Jules). See `AGENTS.md` and `CLAUDE.md`.
